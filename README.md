# Cybersecurity Labs
Hands-on cybersecurity labs covering network analysis, vulnerability assessment, exploitation, and defensive analysis in isolated environments.

## Labs

### [Lab 01 - Isolated Cybersecurity Lab Environment](01-isolated-lab-environment/)
Built an isolated VirtualBox environment using Kali Linux, Ubuntu, and Metasploitable 2 for future offensive and defensive security exercises.

### [Lab 02 - Network Discovery and Port Scanning](02-network-discovery-port-scanning/)
Using Nmap to discover active hosts, perform TCP and UDP port scans, and analyze network traffic with Wireshark.

### [Lab 03 - Service Enumeration](03-service-enumeration/)
Using Nmap service and version detection to identify TCP and UDP services, analyze protocol responses with Wireshark, and investigate information disclosed by running services.

### [Lab 04 - Vulnerability Assessment](04-vulnerability-assessment/)

Performing deeper enumeration and targeted vulnerability assessment of selected services using vulnerability research, Nmap, configuration analysis, and Wireshark to identify weaknesses for further testing in Lab 05.
